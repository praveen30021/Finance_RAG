Part 1

NumPy

The base of everything. ndarray = fast, fixed-type, multi-dimensional array + vectorized maths.

1.1Why NumPy + Mindmap

PointSimple reason
FastLoops run in compiled C, not Python. This is called vectorization (10–100x faster).
Less memoryRaw numbers of one type stored side by side. A list stores pointers to separate objects.
Easy mathsa + b, a * 2, a > 5 work on the whole array — no for loop.
Base libraryPandas, Matplotlib, scikit-learn, TensorFlow all use NumPy arrays.
One-line answer: "What is NumPy?"

"NumPy gives us the ndarray — a fast, fixed-type, n-dimensional array — and vectorized functions that work on the whole array at once without Python loops, because the real work happens in C."

1.5Indexing, Slicing, Iteration

a[2]            # 1-D: 3rd item (index starts at 0)
a[-1]           # last item
m[1, 2]         # 2-D: row 1, column 2   (better than m[1][2])
m[1]            # full row 1
m[:, 1]         # full column 1  <-- very common
m[0:2, 1:3]     # rows 0-1, columns 1-2   (end NOT included)
m[::2, ::-1]    # every 2nd row, columns reversed
t[0, 1, 2]      # 3-D: block 0, row 1, col 2

for row in m:        # loops row by row
for x in m.flat:     # loops every single item
np.nditer(m)         # efficient iterator
Remember

Slice format is start : stop : step and stop is never included. In 2-D always use m[row, col] — m[row][col] creates an extra temporary array and is slower.

1.6View vs Copy (favourite interview trap)

In interview, say this

"A NumPy slice returns a view, not a copy — it shares the same memory, so changing the slice changes the original. This is different from a Python list, where slicing copies. If I need an independent array I write .copy(). Fancy indexing and boolean indexing always return copies."

1.10Broadcasting

Broadcasting = NumPy automatically stretches a smaller array so two different shapes can work together, without actually copying data in memory.

a = np.array([[1,2,3],[4,5,6]])     # (2,3)
a + 10                              # scalar  -> works
a + np.array([10,20,30])            # (3,)    -> works (stretched down)
a + np.array([[10],[20]])           # (2,1)   -> works (stretched across)
a + np.array([10,20])               # (2,)    -> ValueError
# fix: make it a column
a + np.array([10,20])[:, np.newaxis]
Why it is useful (say this)

"Broadcasting lets me write (data - data.mean(axis=0)) / data.std(axis=0) to normalize every column in one line, with no loop and no extra memory, because NumPy only pretends to repeat the smaller array instead of really copying it."

df[(df['age'] > 25) & (df['city'] == 'Delhi')]    # & | ~  with brackets

Number 1 Pandas mistake

Using and / or instead of & / |, or forgetting the brackets around each condition. and works on single True/False, but here every row has its own True/False, so you must use the element-wise operators.

agg vs transform vs apply — know this difference

agg → one row per group (shrinks the data). transform → same number of rows as before (broadcasts the group result back). apply → flexible, can return anything, but it is the slowest.

# classic transform use: each player's share of his team total
df['pct'] = df['runs'] / df.groupby('team')['runs'].transform('sum') * 100

Merge trap

If the key has duplicate values in both tables, you get more rows than you started with (a many-to-many join). Always check df.shape before and after a merge, and use validate='one_to_one' when you expect a clean key.

2.11corr()

df.corr(numeric_only=True)            # Pearson (linear) by default
df.corr(method='spearman')            # rank based - catches non-linear but monotonic
df['a'].corr(df['b'])
df.corr()['price'].sort_values(ascending=False)   # what relates to the target
sns.heatmap(df.corr(numeric_only=True), annot=True, cmap='coolwarm', vmin=-1, vmax=1)
ValueMeaning
+1Perfect positive: one goes up, other goes up
0No linear relation (there may still be a curved relation)
−1Perfect negative: one goes up, other goes down
Two lines that score marks

1. Correlation is not causation. 2. Pearson only measures a straight-line relation; a perfect U-shaped relation can give correlation 0. Also, two features with very high correlation (>0.9) mean multicollinearity — drop one before linear regression.

2.13Missing Values: dropna & fillna

df.isnull().sum()                 # count per column - ALWAYS run first

df.dropna()                       # drop rows having ANY NaN

df.dropna(subset=['salary'])      # drop only if THIS column is missing
df.dropna(axis=1)                 # drop columns instead of rows

df.fillna(0)

df['city'].fillna(df['city'].mode()[0])   # mode for text columns
df.ffill()   df.bfill()                   # carry forward / backward (time series)
df['a'].interpolate()                     # estimate between two known values

Very few missing rowsdropna()

Pandas methods return a new object. df.dropna() alone changes nothing — write df = df.dropna(). Also, NaN == NaN is False, so always use isnull().

2.14Data Types & Cleaning Checklist

df['a'] = df['a'].astype('int32')
pd.to_numeric(df['a'], errors='coerce')     # bad text becomes NaN instead of error

  1. Check df.info() — are numbers stored as text? are dates stored as text?
  2. df.isnull().sum() → decide drop or fill.
  3. df.duplicated().sum() → drop_duplicates().
  4. Clean text: .str.strip().str.lower() (so "Delhi" and " delhi " become one category).

  6. Check outliers with describe() and a boxplot.
  7. Rename columns to clean lowercase names.

Part 5

Rapid-Fire Interview Q&A

45 real questions. Short answers, the way you can actually speak them.

NumPy

1. What is NumPy and why is it faster than a Python list?

NumPy gives the ndarray — a fixed-type, n-dimensional array. It is faster because the loops run in compiled C instead of Python, and because the numbers of one type sit together in memory. This is called vectorization.

2. List vs array — what happens with a + b?

For lists it joins them; for arrays it adds item by item. Lists allow mixed types and can grow; arrays have one type and a fixed size but have all the maths tools.

3. Difference between arange and linspace?

arange takes a step and excludes the end; linspace takes how many numbers you want and includes the end. For plotting I use linspace because the count is guaranteed.

4. What does axis=0 and axis=1 mean?

axis is the direction that disappears. axis=0 goes down the rows and gives one value per column; axis=1 goes across the columns and gives one value per row.

5. Does slicing a NumPy array give a copy?

No, it gives a view — same memory. Changing the slice changes the original. Python lists copy on slicing, so this surprises people. Use .copy() for an independent array; fancy and boolean indexing always copy.

6. ravel vs flatten?

Both make the array 1-D. ravel() returns a view (faster, shares memory), flatten() returns a copy (safe).

7. What is broadcasting? What are its rules?

It lets arrays of different shapes work together by stretching the smaller one — without really copying memory. Rule: compare shapes from the right; each pair must be equal or one of them must be 1, else ValueError.

8. Fancy indexing vs boolean indexing?

Fancy indexing picks by a list of positions in any order; boolean indexing picks by a condition mask. Both return copies.

9. What does np.where do?

It is if-else on the whole array: np.where(cond, value_if_true, value_if_false). With only the condition it returns the positions where it is True.

10. a * b vs a @ b?

* is element-wise multiplication; @ (or np.dot) is matrix multiplication, where inner dimensions must match.

11. How do you handle NaN in NumPy?

np.isnan() to find them (== np.nan never works because NaN is not equal to itself), and np.nanmean / np.nansum to calculate while ignoring them.

12. How do you reduce memory of an array?

Use a smaller dtype, for example astype('float32') instead of float64 — that halves the memory. a.nbytes shows the total.

Pandas

13. Series vs DataFrame?

Series is one labelled column (1-D). DataFrame is a full table (2-D) made of many Series sharing the same index.

14. Why Pandas when NumPy exists?

NumPy arrays hold one type and have no labels. A DataFrame holds different types per column, has column names and row labels, and has ready tools for missing data, grouping, joining and reading files.

15. loc vs iloc?

loc selects by label and the slice end is included; iloc selects by integer position and the end is excluded. loc also accepts a boolean mask, which is why df.loc[mask, 'col'] = x is the safe way to assign.

16. What are the first 5 commands you run on a new dataset?

df.shape, df.head(), df.info(), df.describe() and df.isnull().sum(). Then value_counts() on the category columns.

17. How do you filter rows on two conditions?

df[(df.age > 25) & (df.city == 'Delhi')] — element-wise & and | with brackets around each condition. Plain and/or fails because each row has its own True/False.

18. What is the use of isin()?

It checks membership in a list, so one line replaces many OR conditions: df[df.city.isin(['Delhi','Pune'])]. Put ~ in front for "not in".

19. Explain groupby.

Split-apply-combine: split the rows into groups by a key, apply a calculation to each group, and combine the results into one table. It is the same as SQL GROUP BY.

20. agg vs transform vs apply?

agg gives one row per group (data shrinks). transform gives back the same number of rows, so the group result sits on every row — good for percentage of group or filling NaN by group. apply is flexible but slowest.

21. count() vs size() in groupby?

count() counts non-null values per column; size() counts all rows in the group including NaN.

22. merge vs join vs concat?

merge joins on columns like SQL; join works on the index; concat just stacks tables, rows or columns, without matching keys.

23. Types of joins?

inner keeps only matching keys, left keeps all rows of the left table, right keeps all of the right, outer keeps everything and fills NaN where there is no match.

24. After merging I got more rows than before. Why?

Because the key is duplicated in both tables, so it became a many-to-many join. I check shape before and after, and use validate='one_to_one' when the key should be unique.

25. pivot_table vs pivot vs crosstab?

pivot only reshapes and errors on duplicate index/column pairs. pivot_table reshapes and aggregates (default mean). crosstab is a shortcut of pivot_table for counting two categories.

26. What does set_index do and when do you use it?

It makes a column the row label. After that .loc lookups are fast and readable, joins on that key are easier, and date slicing like df.loc['2021'] works. reset_index() turns it back into a normal column — I use it after groupby.

27. How do you handle missing values?

First measure with isnull().sum(). If very few rows, drop them. If a column is mostly empty, drop the column. Else fill: mean for clean numeric data, median when outliers exist, mode or "Unknown" for text, and ffill or interpolate for time series.

28. Why mean is risky for filling?

Because outliers pull the mean. With a few very large salaries, the mean is not a typical value, so the median is safer.

29. What is SettingWithCopyWarning?

It comes from chained assignment like df[df.a>1]['b']=0, where Pandas cannot tell if the first step gave a view or a copy, so the change may be lost. The correct way is df.loc[df.a>1,'b']=0.

30. apply vs map vs vectorized operations?

map works on a Series with a dict or a function; apply works on rows or columns; both run a Python loop internally. A vectorized operation or np.where is much faster, so I use apply only when there is no vectorized way.

31. cut vs qcut?

cut makes bins of equal ranges that you define; qcut makes bins with an equal number of rows (quantiles).

32. How do you handle a CSV file too big for memory?

Read only needed columns with usecols, set smaller dtypes, use chunksize to process it in pieces, convert repeated text to category, or switch to Parquet.

33. value_counts vs groupby.count?

value_counts works on one Series and sorts by frequency; groupby is more general and can aggregate many columns at once. For class imbalance I use value_counts(normalize=True).

34. What does corr() tell you and what is its limit?

It measures the linear relation between numeric columns, from −1 to +1. Limits: it only sees straight-line relations, and correlation is not causation. Very high correlation between two features means multicollinearity.

Matplotlib

35. Figure vs Axes vs Axis?

Figure is the whole canvas, Axes is one plot drawn on it, and Axis is the x or y number line of that plot. One figure can hold many Axes; each Axes has two Axis objects.

36. pyplot vs object-oriented interface?

pyplot is a state machine that remembers the current figure, so commands apply implicitly. The OO interface gives me Figure and Axes objects, which is safer for multiple subplots and reusable functions.

37. Histogram vs bar chart?

Histogram is for one numeric column with ranges on the x-axis and bars touching; bar chart is for categories with gaps and a reorderable order. Histogram shows distribution, bar shows comparison.

38. How do you plot 4 charts in one figure?

fig, ax = plt.subplots(2,2, figsize=(12,8)), draw on ax[0,0] to ax[1,1], then plt.tight_layout(). Add sharey=True if they must be compared on the same scale, and GridSpec if the panels need different sizes.

39. My saved image is blank. Why?

Because savefig() was called after plt.show(), and show clears the figure. Save first, then show.

40. Which colormap do you choose and why?

Sequential like viridis for low-to-high values, diverging like coolwarm when zero is a meaningful centre such as correlation, and qualitative like tab10 for categories. I avoid jet because it is not perceptually uniform and is bad for colour-blind users.

Seaborn & general

41. Seaborn vs Matplotlib?

Seaborn is built on Matplotlib. It works directly with DataFrames, does the statistics itself and gives complex charts in one line; Matplotlib gives low-level control. I use both — Seaborn for the chart, Matplotlib to fine-tune it.

42. Figure-level vs axes-level in Seaborn?

Axes-level functions draw on one Axes and accept ax=. Figure-level functions (relplot, displot, catplot) create their own figure, return a FacetGrid and support col/row faceting, but do not accept ax= and are sized with height and aspect.

43. boxplot vs violinplot?

Boxplot shows the five-number summary and outliers. Violin shows the full distribution shape with a KDE plus a small box inside. The key point: a boxplot cannot reveal a bimodal distribution, the violin can.

44. How do you check correlation of all features and what do you do with it?

sns.heatmap(df.corr(numeric_only=True), annot=True, cmap='coolwarm', vmin=-1, vmax=1). I look at which features relate to the target, and drop one of any pair with correlation above about 0.9 to avoid multicollinearity.

45. Walk me through your EDA process.

Load with read_csv, then shape, info, describe and isnull().sum(). Clean: fix dtypes, missing values, duplicates, messy text. Top 15 Mistakes (avoid these and you are already ahead)

1Using and/or instead of &/|, or forgetting brackets in a filter.
2Chained assignment df[mask]['col'] = x — use df.loc[mask,'col'] = x.
3Forgetting that Pandas methods return a new object — df.dropna() alone changes nothing.
4Mixing up loc (end included) and iloc (end excluded).
5Forgetting index=False in to_csv.
6Merging on a duplicated key and silently getting extra rows.
7Filling missing values with the mean when outliers exist — use the median.
8Doing maths on numbers stored as text, or comparing dates stored as text.
9Using apply/iterrows where a vectorized operation exists.
10Forgetting that a NumPy slice is a view, so the original changes too.
11Checking NaN with == instead of isnan/isnull.
12Calling savefig() after show() and getting a blank file.
13Expecting figsize to work on a Seaborn figure-level plot.
14Drawing a bar chart whose y-axis does not start at 0.
15Saying a high correlation proves a cause.
Final tip for the interview

Never answer with only a function name. Add why — "two numeric columns, so a scatter plot", "outliers present, so median not mean", "the key repeats, so I checked the shape after the merge". That one habit is the difference between someone who memorised the syntax and someone who has actually worked with data.
